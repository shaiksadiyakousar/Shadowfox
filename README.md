# ShadowFox Python Development Internship

Task submissions for the ShadowFox Python Development Internship, covering core Python fundamentals, web scraping, game development, and data analysis.

## Task 1 (Beginner Level) — 5 programs completed

| File | Topic | What it demonstrates |
|---|---|---|
| [Task1_Beginner/1_variables.py](Task1_Beginner/1_variables.py) | Variables | Declaring variables, checking data types, and calculating simple interest |
| [Task1_Beginner/2_if_condition.py](Task1_Beginner/2_if_condition.py) | If Condition | BMI classification, city-to-country lookup, and comparing two cities |
| [Task1_Beginner/3_for_loop.py](Task1_Beginner/3_for_loop.py) | For Loop | Random dice simulation and a jumping-jacks workout loop |
| [Task1_Beginner/4_dictionary.py](Task1_Beginner/4_dictionary.py) | Dictionary | Working with lists of tuples and comparing trip expenses |
| [Task1_Beginner/5_inheritance.py](Task1_Beginner/5_inheritance.py) | Inheritance | Using a base phone class with Apple and Samsung child classes |

**Run locally:**
```bash
python Task1_Beginner/1_variables.py
python Task1_Beginner/2_if_condition.py
python Task1_Beginner/3_for_loop.py
python Task1_Beginner/4_dictionary.py
python Task1_Beginner/5_inheritance.py
```
> A few of these are interactive and will prompt for input while running.
